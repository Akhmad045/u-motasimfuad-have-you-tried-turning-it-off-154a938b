`main.py` writes a single tech-support line, 113 characters, to `/output/entry.txt`:

**Let's turn it off and on again together — I'll count to ten, you pray, and we'll both pretend this is a real fix.**

The agent doesn't just recite the classic reboot script — he turns it into
a shared ritual, counts to ten, asks the customer to pray, and cheerfully
admits the "fix" is pretend. The humour comes from the agent's own
cheerful uselessness, never from the customer.
